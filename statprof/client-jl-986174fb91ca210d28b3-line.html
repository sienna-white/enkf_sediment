570 """
571 @main
572
573 This macro is used to mark that the binding `main` in the current module is considered an
574 entrypoint. The precise semantics of the entrypoint depend on the CLI driver.
575
576 In the `julia` driver, if `Main.main` is marked as an entrypoint, it will be automatically called upon
577 the completion of script execution.
578
579 The `@main` macro may be used standalone or as part of the function definition, though in the latter
580 case, parentheses are required. In particular, the following are equivalent:
581
582 ```
583 function (@main)(args)
584 println("Hello World")
585 end
586 ```
587
588 ```
589 function main(ARGS)
590 end
591 @main
592 ```
593
594 ## Detailed semantics
595
596 The entrypoint semantics attach to the owner of the binding owner. In particular, if a marked entrypoint is
597 imported into `Main`, it will be treated as an entrypoint in `Main`:
598
599 ```
600 module MyApp
601 export main
602 (@main)(args) = println("Hello World")
603 end
604 using .MyApp
605 # `julia` Will execute MyApp.main at the conclusion of script execution
606 ```
607
608 Note that in particular, the semantics do not attach to the method
609 or the name:
610 ```
611 module MyApp
612 (@main)(args) = println("Hello World")
613 end
614 const main = MyApp.main
615 # `julia` Will *NOT* execute MyApp.main unless there is a separate `@main` annotation in `Main`
616 ```
617
618 !!! compat "Julia 1.11"
619 This macro is new in Julia 1.11. At present, the precise semantics of `@main` are still subject to change.
620 """

622 if !isempty(args)
623 error("USAGE: `@main` is expected to be used as `(@main)` without macro arguments.")
624 end
625 if isdefined(__module__, :main)
626 if Base.binding_module(__module__, :main) !== __module__
627 error("USAGE: Symbol `main` is already a resolved import in module $(__module__). `@main` must be used in the defining module.")
628 end
629 end

631 # Force the binding to resolve to this module
632 global main
